# Wallset

## EN — English

Open format for static wallpapers: one master source → one clear set of JPG files → adapters for operating systems. Status: `v0.1.0-draft`; no compatibility promise on v0.x.

- Only static wallpapers; video/WebGL/live wallpapers are non-goals.
- Only JPEG output: quality 92, 4:4:4, sRGB, progressive, no EXIF.
- The master (SVG/PNG or script + seed) stays in git; JPGs are build artefacts.
- Targets: `linux:<de>`, `windows`, `macos`, `freebsd:<de>`, `haiku`.
- Origin is mandatory: `own | procedural | ai | mixed`. Images CC0, code MIT.

Normative spec: [`SPEC.md`](SPEC.md). Localisation rule: [`I18N.md`](I18N.md).
Contact / GitHub: `atlas3512` (sysBlank) — sain.3512@gmail.com.
Spec: **Wallset** v0.1. Repository: `wallscreen`.

## Commands / Befehle / Команды / 命令 / コマンド / 명령

```bash
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements.txt

.venv/bin/python tools/wps.py validate packs/aurora-night
.venv/bin/python tools/wps.py render   packs/aurora-night --out dist
.venv/bin/python tools/wps.py pack     packs/aurora-night --out dist
.venv/bin/python tools/wps.py install  packs/aurora-night --target linux:hyprland --out dist
.venv/bin/python tools/wps.py capabilities
.venv/bin/python -m unittest discover -s tests -v
```

EN: `install` writes only into `--out`; it never touches system configuration.
DE: `install` schreibt nur in `--out`; Systemkonfigurationen werden nie verändert.
RU: `install` пишет только в `--out`; системные конфиги не трогаются.

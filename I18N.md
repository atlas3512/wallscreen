# Localisation policy / Lokalisierungsrichtlinie / Политика локализации / 本地化政策 / ローカライズ方針

## EN

All comments and descriptions in this repository must be written in five
languages: **English, German, Russian, Chinese and Japanese**. English is the
canonical source of truth. Every translation must be updated in the same commit
as the English text. Code identifiers, file names and JSON keys stay in English.
Licence texts and third-party legal code stay in their original language.
Machine translation is allowed as a first draft but must be reviewed by a human.

## DE

Alle Kommentare und Beschreibungen in diesem Repository müssen in fünf Sprachen
verfasst werden: **Englisch, Deutsch, Russisch, Chinesisch und Japanisch**.
Englisch ist die verbindliche Referenz. Jede Übersetzung muss im selben Commit
wie der englische Text aktualisiert werden. Code-Bezeichner, Dateinamen und
JSON-Schlüssel bleiben auf Englisch. Lizenztexte und juristische Texte Dritter
bleiben in ihrer Originalsprache. Maschinelle Übersetzung ist als erster Entwurf
erlaubt, muss aber von einem Menschen geprüft werden.

## RU

Все комментарии и описания в этом репозитории должны быть написаны на пяти
языках: **английском, немецком, русском, китайском и японском**. Английский
является каноническим источником. Каждый перевод должен обновляться в том же
коммите, что и английский текст. Идентификаторы кода, имена файлов и ключи JSON
остаются на английском. Тексты лицензий и сторонние юридические тексты
остаются на языке оригинала. Машинный перевод допустим как черновик, но должен
быть проверен человеком.

## ZH

本仓库中的所有注释和说明必须使用五种语言撰写：**英语、德语、俄语、中文和日语**。
英文为权威原文。每次翻译必须与英文文本在同一提交中更新。代码标识符、文件名和
JSON 键保持英文。许可证文本和第三方法律文本保持原文语言。机器翻译可作为初稿，
但必须经过人工校对。

## JA

このリポジトリ内のすべてのコメントと説明は、**英語・ドイツ語・ロシア語・中国語・
日本語**の5言語で記述してください。英語を正規の原文とし、すべての翻訳は英語の
テキストと同じコミットで更新する必要があります。コードの識別子、ファイル名、
JSON キーは英語のままとします。ライセンス本文および第三者が作成した法的文書は
原文の言語のままとします。機械翻訳は下書きとして許可されますが、人間の確認が
必要です。
